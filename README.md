项目简介
BJKS 是一款基于 Tauri 2.x + Rust 的 Windows 本地文件快速搜索工具，功能包括：

多关键词文件名搜索（空格分隔，命中所有关键词）
扩展名过滤与文件类型快速选择（音频、压缩、文档、可执行、图片、视频、文件夹等）
文件大小、修改时间排序，支持组合排序
右键打开文件/打开所在目录/复制路径
屏蔽目录、屏蔽文件模式、屏蔽扩展名设置
索引缓存与手动重新扫描
